# fulgurite feedback

Bug reports, ideas and crash reports for the [fulgurite](https://github.com/fulgurite-plugin) beta.
The app opens these forms for you with its version and your system filled in: **Help › Report a Bug…**, **Help › Suggest a Feature…**, or **Settings › General › Feedback** (iPhone and iPad). After a crash it offers to report it the next time it opens.

fulgurite 베타의 버그, 아이디어, 충돌 신고를 받는 곳입니다. 앱의 **도움말 › 버그 신고…**, **도움말 › 기능 제안…**, 또는 **설정 › 일반 › 피드백**(iPhone·iPad)에서 버전과 시스템이 채워진 채로 열립니다. 앱이 충돌하면 다음에 열 때 신고할지 묻습니다.

Plugin issues belong in the plugin's own repository (Settings › Plugins links to it).
플러그인 문제는 그 플러그인 저장소에 올려 주세요(설정 › 플러그인에 링크가 있습니다).
